# 界面验证

2026-10-25，在独立 Chromium 测试环境运行本仓库公开重建界面。截图为本地合成数据，不是原竞赛交付截图，也不使用个人浏览器资料。

| 检查 | 结果 | 证据与范围 |
| --- | --- | --- |
| 320、375、768、1440 CSS px | pass | 稳定状态截图，无页面级横向溢出 |
| 200% 文字放大 | pass | 375px，所有元素的原计算字号加倍 |
| 文字间距覆盖 | pass | 375px，行高1.5、字距.12em、词距.16em、段距2em |
| 代表性文字对比 | pass | 从实际计算前景/背景色测量；11 组标题、说明、状态与按钮，不是全页面审计 |
| 键盘入口与面板切换 | pass | Tab 跳转、Enter 激活和原生控件；完整屏幕阅读器检查未进行 |
| 减少动态效果 | pass | reduced-motion 模式；界面无必需动画 |
| 五类服务、六条样例 | pass | 逐条切换，对话与证据对应 |
| 消息时点 | pass | DEMO-006 第2条消息后不出现第3条的证据 |
| 人工草稿保护 | pass | 重分析与切换会话保留编辑文本 |
| 高风险核对 | pass | 两项核对前采纳/复制禁用；修改草稿后核对失效 |
| 反馈与终稿检查 | pass | 原样、改写、拒绝分别记录；示例越权承诺被服务端拒绝 |
| 连接失败 | pass | 保留草稿和最后确认时点，禁用采纳，重新连接可恢复 |
| 原始 JSON | pass | 320px 局部滚动，不撑宽页面 |
| 页面脚本错误 | pass | 上述流程无 pageerror |
| 真实平台、在线模型、真人效果 | not tested | 公开版不包含这些能力 |
| Safari、Firefox、系统高对比模式 | not tested | 只测试现有浅色界面；封面另提供明暗两版 |

自动复核脚本为 [tools/browser-qa.cjs](../tools/browser-qa.cjs)，使用作品集已有的 Playwright 测试环境；输出在忽略目录 `tmp/browser-qa/`。运行工作台本身不需要 Playwright。

不宣称完整 WCAG 合规。设计依据见 [UI_AUDIT.md](UI_AUDIT.md)。
