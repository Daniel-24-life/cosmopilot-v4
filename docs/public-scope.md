# 公开范围

## 公开了什么

本仓库公开的是一套基于知微 CosmoPilot V4.0 机制重新实现的离线参考项目，重点展示：

- 五类消费者服务场景与六条独立编写的合成样例；
- 按消息时点读取内容，避免使用未来证据；
- 已核对记录、消费者自述、系统推断三类证据；
- 六步本地 Trace；
- 候选草稿的人工核对、原样采纳、改写采纳和拒绝；
- 高风险核对、有限措辞检查、幂等写入与上下文失效；
- Python 标准库、SQLite 和原生前端组成的本地可运行路径。

这些内容用于产品展示、架构交流、AI Coding 过程说明和离线测试参考。

## 没有公开什么

本仓库不包含：

- 官方数据原件、竞赛原始会话或真实消费者信息；
- 品牌资产、账号、密钥和外部平台接口；
- 内部日志、完整 Prompt 链、私有目录或个人路径；
- 原工程的完整源码、生产配置或团队内部协作记录；
- 在线模型、真实发送、退款、补发、建单或其他业务写操作；
- 可证明真实客服效果、商业收益或生产稳定性的结果。

六条样例是为公开仓库重新编写的合成内容，不是原数据的脱敏副本。

## 可以据此说明什么

可以说明这份公开实现具有本地运行的分析、时点筛选、证据展示、草稿复核和反馈记录机制；也可以依据源码讨论这些机制如何落到 HTTP、SQLite 与前端交互中。

不能据此声称：

- 仓库是精确的原版 V4.0 源码；
- 已接入品牌或电商平台；
- 已通过真人客服、生产环境或真实业务数据验证；
- 有限规则检查等于全面医疗、法律或品牌合规；
- 本地采纳等于消息已经发送或业务已经完成；
- 历史 V4.0 报告中的测试数量和通过记录是本仓库的新成绩。

## 项目与团队归属

原项目为团队协作成果。本人负责产品、视觉、验收，并组织前端实现；技术同学主要负责数据、模型和后端，双方共同联调。公开仓库展示的是经选择和重建的公共机制，不改变原有分工，也不把团队成果改写为个人独立完成或 AI 独立完成。

## 名称与背书

“知微 CosmoPilot”用于标识本团队项目和这份公开参考实现。本仓库不是品牌官方产品，不表示品牌、赛事主办方或相关平台对该实现提供官方背书、认证或部署授权。
