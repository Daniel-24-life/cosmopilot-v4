# 公开界面设计依据

受众为招聘者和技术合作者，主任务是用一条合成会话看懂证据、草稿复核和本地反馈。视觉沿用 V4.0 材料中的紫色强调、浅灰画布与白色面板；界面为公开参考版重建，不冒充原始交付截图。

| 优先级 | 层级 | 依据与目标 | 置信度 | 验证条件 |
| --- | --- | --- | --- | --- |
| P1 | Required | 数据身份、采纳和发送不能混淆 | 高 | 所有状态保留合成、离线、未发送标识 |
| P1 | Required | 新分析不能覆盖人工文本，高风险核对须随修改失效 | 高 | 编辑、切换、重分析及反馈实际操作 |
| P1 | Required | 选中会话和迟到响应不能串台 | 高 | 请求令牌、清空旧面板与快速切换检查 |
| P2 | Contextual | 对话、人工草稿和决策依据分区，比堆叠指标更有阅读价值 | 高 | 桌面三栏、窄屏顺序重排，六条样例覆盖五服务 |
| P3 | Preference | 延续产品自己的紫色视觉，不套用其他作品的青绿模板 | 高 | 封面、界面和截图一致 |

浏览器验证另见 UI_QA.md，测试结果不从历史材料继承。
