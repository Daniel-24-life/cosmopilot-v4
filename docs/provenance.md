# 来源与重建说明

## 来源关系

本仓库以知微 CosmoPilot V4.0 冻结规格中已经形成的产品机制为参考，重新编写了一套可公开、可离线运行的最小实现。参考内容包括五类服务、按时点读取、三态证据、六步 Trace、人工草稿复核、采纳与拒绝、幂等保护及上下文失效。

公开代码不是从原工程直接导出的完整版本。运行文件、页面和六条样例均面向公开展示重新组织，其中样例为独立编写的合成内容。

## 为什么称为重建

原工作区后续已进入 V4.1 候选开发，当前源码不能直接当作 V4.0 的原始版本发布。另有 `source_before_v41.zip`，但它是混合快照，不能证明其中每个文件都精确对应冻结时点的原版 V4.0。因此，本仓库不声称是“V4.0 原版源码”“完整复刻”或“逐文件还原”。

更准确的表述是：这是基于 V4.0 冻结机制重建的公开离线参考实现。它保留适合展示和阅读的行为约束，同时用新的样例、较小的代码结构和明确的无外发边界重新实现。

## 资料处理原则

重建过程中遵循以下范围：

- 规格用于理解机制，不复制官方数据原件；
- 原工程保持只读，不把内部工作区当作公开依赖；
- 不复制真实或竞赛会话、完整日志、完整 Prompt 链、账号信息和个人路径；
- 不在公开文档中写入原工作区的绝对路径；
- 历史报告只用于理解当时的工程背景，不把其中的用例数量或通过结果计为本仓库成绩；
- V4.1 候选内容不作为本仓库已经完成的 V4.0 成果。
